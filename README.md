# Estética Spa Sayuri

Sitio web responsive desarrollado con HTML, CSS y JavaScript, sin dependencias de instalación.

## Cómo abrirlo

1. Descomprime `estetica-spa-sayuri.zip`.
2. Abre la carpeta `estetica-spa-sayuri` en Visual Studio Code.
3. Abre `index.html` en tu navegador. Para una experiencia de desarrollo más cómoda, puedes instalar la extensión **Live Server** en VS Code y seleccionar **Open with Live Server**.
4. Para editar textos, modifica `index.html`; para colores y diseño, `css/styles.css`; para el menú móvil y el año del pie de página, `js/script.js`.

## Estructura

- `index.html`: contenido y secciones.
- `css/styles.css`: diseño adaptable a móviles, tabletas y computadores.
- `js/script.js`: navegación móvil y año automático.
- `assets/logo-sayuri.png`: logo original entregado.
- `assets/galeria/`: las seis fotografías originales proporcionadas.

## Antes de publicar

- Revisa los enlaces de Instagram y Facebook y reemplaza las direcciones genéricas por las URL exactas de los perfiles de Sayuri.
- Confirma los datos de contacto y los servicios que desea ofrecer.
- El sitio usa Google Fonts para la tipografía; si no hay conexión, se usarán fuentes alternativas instaladas.
- Los enlaces de WhatsApp abren una conversación con el número correspondiente.
- Para publicarlo puedes usar un hosting estático, por ejemplo GitHub Pages. Sube todos los archivos manteniendo la estructura de carpetas.

## Responsive y accesibilidad

Incluye navegación móvil, imágenes adaptables, enlaces con foco visible, texto alternativo en imágenes, enlace para saltar al contenido y soporte para preferencia de movimiento reducido.

## Sección Firma

La sección «Firma tu asistencia» es solo una interfaz visual. El formulario no envía ni almacena credenciales; la integración de autenticación y registro debe implementarse posteriormente con un backend seguro.
